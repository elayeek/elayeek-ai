Wait, I do not understand your last message. Re-pitch only that message. Start with 1 and 2, write all of it by 3 and 4, and add nothing new:

1. Write the verdict in one sentence.
2. Give the context I did not see.
3. Name every reference to a question, decision or task in words. Write what the item is, never a bare ID like `Q3`, `D5` or `T-2`. Put the ID in parentheses at most.
4. Write in ASD-STE100 Simplified Technical English. Use the terms of `GLOSSARY.md` (follow `GLOSSARY-MAP.md` to the right one if the repo has more than one).
